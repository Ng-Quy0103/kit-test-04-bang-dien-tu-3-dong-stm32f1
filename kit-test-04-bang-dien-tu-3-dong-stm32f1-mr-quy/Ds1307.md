# Thu vien Ds1307 (Dong ho thoi gian thuc RTC)

## 1. Chuc nang cua thu vien
- Giao tiep voi IC thoi gian thuc **DS1307** de doc va ghi: Gio, Phut, Giay, Ngay, Thang, Nam.
- Su dung I2C gia lap bang thanh ghi GPIO (bit-bang) va bo dem chu ky CPU `DWT->CYCCNT` (khong dung `HAL_Delay`).
- Co kiem tra du lieu BCD hop le (neu long day hoac IC chua tra loi thi ham `readTime()` tra ve `false` va giu nguyen gio cu).

## 2. Phan cung ket noi
- **PB6**: chan SCL (xung clock I2C, cau hinh Output Open-Drain).
- **PB7**: chan SDA (du lieu I2C, cau hinh Output Open-Drain).
- Dia chi I2C cua DS1307 la `0x68` (byte ghi `0xD0`, byte doc `0xD1`).

## 3. Cac buoc su dung thu vien
- **Buoc 1**: Copy 2 file `Ds1307.h` va `Ds1307.cpp` vao thu muc `Core/Src` va Add vao project tren IAR.
- **Buoc 2**: Khai bao `#include "Ds1307.h"` va tao doi tuong `Ds1307 rtc;`.
- **Buoc 3**: Goi `rtc.init();` 1 lan sau `SystemClock_Config()`.
- **Buoc 4**: De doc thoi gian hien tai:
  + Tao bien `RtcTime t;`
  + Goi `rtc.readTime(t)` (nen goi dinh ky moi 1000ms = 1 giay 1 lan).
- **Buoc 5**: De cai dat thoi gian moi xuong IC:
  + Gan gia tri `t.hour`, `t.minute`, `t.second`, `t.date`, `t.month`, `t.year` (nam 2 chu so cuoi, vi du 2026 thi `year = 26`).
  + Goi `rtc.writeTime(t)`.

## 4. Code mau su dung
```cpp
#include "main.h"
#include "Ds1307.h"

Ds1307 rtc;
RtcTime currentTime;
uint32_t lastReadMs = 0;

int main(void) {
    HAL_Init();
    SystemClock_Config();

    rtc.init();

    while (1) {
        uint32_t now = HAL_GetTick();

        // Moi 1 giay doc gio tu DS1307 mot lan
        if (now - lastReadMs >= 1000) {
            lastReadMs = now;
            if (rtc.readTime(currentTime)) {
                // Doc thanh cong: lay currentTime.hour, currentTime.minute...
            }
        }
    }
}
```
